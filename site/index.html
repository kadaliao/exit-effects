Exit Effects

Window animations made by the community for Exit. Each one is a single Metal file.

Get Exit Submit an effect

Install

  1. In Exit 0.3 or later: Settings → Market, then Install. Installed effects update themselves.
  2. Or download the .metal file into ~/Library/Application Support/Exit/Effects/. It shows up right away.

Submit yours

  1. Write one with the authoring guide, or let Exit's AI write it.
  2. In Exit, click Submit on your effect, or open a submission and paste the code. Pull requests work too.
  3. A bot compiles it, checks the first and last frames and the speed, and renders a preview. After a quick review it appears here.
